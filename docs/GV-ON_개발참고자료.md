## 1. 한 줄

GV-ON은 Global Vision 마케팅 광고 업무를 위한 **사람형 AX 운영 책상**이다.  
시중 AI 브라우저(ASIDE 등)보다 **이 PC의 권한·금고·로컬 LLM**을 더 쓰되, 비밀번호는 OS 금고에만 둔다.

철학: **사람이 할 판단은 사람, 반복 가능한 것은 AI.**  
조회는 자동. 입찰·ON/OFF·결제·목표는 사람 승인.

| 5 | VL이 화면을 보고 좌표·키보드·마우스가 사람과 같게 | L1 DOM → L2 a11y → L3 VL SoM → **L4는 승인 후** |
| 6 | 유튜브·페이스북·인스타·틱톡·커뮤니티 | 프로필·디바이스 프리셋(PC/태블릿/모바일) |

## 4. 사용 환경 요약 (첨부 MD 1부)

매일 쓰는 곳.

- 네이버 검색광고 `ads.naver.com` — 매니저 1 → 브랜드 운영 계정 전환. 입찰 전권은 계정책임자 실계정
- 네이버 애널리틱스 `analytics.naver.com` — API 없음. **12화면/일** (사이트 2 × 기간 3 × 화면 2)
- 구글 애즈 `ads.google.com` — MCC + 계정 7. 비용은 며칠간 사후 상향
- 카카오 키워드/모먼트, 모비온 — 잔액·급등 확인
- GV-ONE 사내망 `menus/menu10/` — 목표설정·성과. 지정 메뉴만 (S6)
- OneDrive 엑셀 3종 — 브라우저는 **직접 안 씀**. 승인 도구만 (S4)

브랜드: 썬볼트 · 코리아팩 · 코리아텍 · 굿프라이스 · 썬볼트온라인. **섞지 않음.**

판단 사슬: 노출 → 클릭 → 문의 → 매출.

## 5. 로컬 스택 (담당자 PC)

| 구성 | 값 |
|---|---|
| OS | Windows 11 우선, 이후 macOS |
| 모델 실행 | LM Studio 로컬 전용 |
| 허브 | Hermes — 내부 / 외부(격리) / 문지기 |
| GPU0 | Qwen, 임베딩, 리랭크. 잠금 |
| GPU1 | 32GB. 번역·OCR·수확 판정 |
| 직원 | Titan XP 12GB. 8B+VL+BGE. 30B 불가 |
| 회사 서버 | Mac Studio M1 Ultra 128GB, Tailscale 나중에 |
| 기록 | Qdrant 로컬. MD 누적 채택 안 함 |
