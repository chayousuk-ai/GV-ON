# 마케팅 업무 전용 브라우저 — 사용 환경 정의 및 요구사항 (AI 제공용 MD)

> 브라우저를 설계·구현할 AI(로컬 코딩 에이전트 그룹 포함)에게 그대로 제공하는 문서다.
> 1부는 담당자가 **실제로 쓰는 페이지·계정·메뉴·목적·반복 업무**의 정의, 2부는 그것을 자동화할 브라우저의 요구사항이다.
> 사내 철학: "사람이 해야 할 판단은 사람이, 반복 가능한 모든 것은 AI가."
> 2026-09-16 개정: 로컬 AI 스택 실설치 반영(LM Studio·Hermes 허브·문지기), 보안 통로 정책(S7~S10) 추가, GV-ONE v8 화면 반영. **금고 항목명 체계와 계정 인벤토리 참조는 변경 없음.**

## 3. 앞으로 하고자 하는 것 — 원하는 브라우저의 형태

- 위 매체 전부를 **한 브라우저 안의 프로필로 상시 로그인** 상태로 두고, 정해진 화면 세트를 한 번에 열어 자료 로딩까지 확인한다.
- 애널리틱스처럼 API가 없는 화면은 브라우저가 **직접 기간을 넣고 조회를 누르고 값을 읽어** AI에 넘긴다. 사람 캡처가 사라진다.
- 매체 화면을 보고 있으면 옆 패널에 **같은 계정·기간의 서버 DB 값**이 붙어서 차이가 바로 보인다.
- 사람이 한 번 시연한 클릭·입력 흐름을 **스킬로 저장**해 이름으로 재실행한다. 로그인 포함.
- 모든 조회·액션은 시각과 함께 기록되어 "그때 화면 값이 얼마였나"를 나중에 증빙할 수 있다.
- 이 브라우저는 마케팅에서 시작하지만, 궁극적으로 **담당자 PC를 통제하는 자동화 허브**로 확장된다.

# 2부. 브라우저 요구사항

## 4. 개발 배경과 제1 원칙

1. 시중 AI 브라우저는 사람이 눈으로 하던 모든 액션을 시각 기반으로 자동화·자율화·능동화할 수 있음을 보여줬다.
2. 그러나 무료 버전의 한계, 우리 업무 목적과의 불일치, 그리고 **내 PC의 인증서·비밀번호를 외부 제작 브라우저에 맡길 수 없는 보안 문제**로 자체 개발한다.
3. **제1 원칙: 이 브라우저를 통해 내 컴퓨터를 통제할 수 있어야 한다.** 좌표 클릭·키 입력(아이디·비밀번호 포함)·스크롤·전체 화면 캡처까지 모든 액션을 기록·재생한다. 액션은 좌표값 + 플러그인 + 스킬로 구성한다.
4. 좌표 단독은 화면 개편에 취약하므로 DOM 셀렉터 우선 + 좌표 폴백의 하이브리드로 구현한다.
5. 메신저 웹 버전처럼 "웹이라서 안 되는" 제한이 없어야 한다.
6. **Windows 우선** 개발, 완료 후 macOS.

## 5. 기능 요구사항

### F1. 프로필·화면 세트 (필수)
- 매체·계정별 세션 영구 유지(프로필 분리), 네이버 다중 계정 동시 로그인.
- 화면 세트("아침 브리핑" 등) 정의 → 전 탭 일괄 오픈 + 자료 로딩 완료 확인.

### F2. 액션 레코딩·스킬 (필수 — 제1 원칙)
- 시연한 액션 시퀀스를 스킬로 저장·재생. 로그인 스킬은 금고에서 자격 증명을 주입하되 화면·로그·AI에 값이 보이지 않게.
- 셀렉터 실패 시 좌표 폴백, 그래도 실패하면 중단 후 알림(무한 재시도 금지).
- 신규 계정의 금고 등록은 별도 마스킹 입력 팝업(●●●)으로 받는다 — 값이 채팅·기록·로그 어디에도 남지 않게. AI는 항목명과 등록 결과만 취급한다.

### F3. 정형 화면 값 추출 (필수 — 최우선 적용: 네이버 애널리틱스)
- 기간 입력 → 조회 실행 → DOM에서 값 구조화 추출.
- **기간 가드**: 화면에 실제 반영된 조회 기간을 다시 읽어 요청 기간과 일치할 때만 값을 내보낸다.
- 결과 `{화면, 계정, 기간, 지표: 값, 추출시각, 스크린샷}` JSON. 값이 없으면 없다고 기록 — 추정·보간 금지.

### F4. 사이드 패널 실시간 대조 (필수)
- 현재 탭의 계정·기간을 인식해 서버 DB 값을 나란히 표시, 차이 강조.
- 알려진 정상 차이(노출 일의 자리 지연 집계, 반올림 방식)는 "정상 범위"로 구분. **비용 차이는 항상 경고**.

### F5. AI 패널 (필수)
- 로컬 AI 에이전트에 명령 전달, "이 화면 값 보내기"로 추출값 직접 전달. 기입·검증 결과 표시.

### F6. 감사 로그·작업 기록 DB (필수)
- 모든 조회·추출·액션을 `언제·어느 화면·어떤 기간·어떤 값/액션`으로 기록 — 사후 보정에 대비한 시점 증빙.
- 작업 기록은 **로컬 Qdrant에 적재해 RAG 검색**. MD 파일 누적 방식은 지속·반복 업무에 부적합해 채택하지 않는다.

### F7. 루틴 스케줄러 (권장)
- 화면 세트·스킬 정시 자동 실행(예: 매일 아침 애널리틱스 6구간). 실패 시 재시도 없이 알림.

### F8. 분석·콘텐츠 보조 (권장)
