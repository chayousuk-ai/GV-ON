# GV-ON

이 저장소에서 받으세요. 채팅 창 다운로드는 막혀 있습니다.

## C:\\GV-ON 에 받기 (CMD)

```
cd /d C:\
if exist GV-ON\package.json (cd GV-ON && git pull) else git clone https://github.com/chayousuk-ai/GV-ON.git GV-ON
cd /d C:\GV-ON
npm install
```

실행:

```
cd /d C:\GV-ON
npm run desktop
```

또는 `windows\실행.bat`. Node 24 되면 됩니다.
