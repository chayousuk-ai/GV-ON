# GV-ON — 윈도우 설치 · Grok CLI 소스

## 두 파일

| 파일 | 용도 |
|---|---|
| GV-ON-Windows.zip | 압축 풀고 `설치.bat` 더블클릭 |
| GV-ON-소스.zip | 같은 소스. CMD에서 Grok CLI로 이어서 수정 |

필요: **Node.js 22**. 없으면 [nodejs.org](https://nodejs.org) 설치.

설치 후 바탕화면 `GV-ON.bat` → Chromium 창(사이트에는 Chrome으로 보임).

아직 없는 것: 광고 사이트 실로그인 CDP, Qdrant·LM Studio 실연결, NSIS Setup.exe. 그 작업은 GROK-CLI.md 를 보고 이 폴더에서 이어 합니다.
